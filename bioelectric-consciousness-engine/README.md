# Bioelectric Consciousness Engine

A cinematic bioelectric/neural visualization built with **Three.js, WebGL and GLSL**. Click anywhere or use **Manual Override** to trigger simulated neural impulses while the HUD tracks live state.

### Run

Open `dist/index.html` in a modern browser, or serve the project through a local HTTP server for best module-loading compatibility.
